# PROJECT: THE CREATIVE PLAYGROUND
## An Experimental Personal Portfolio Website
### Created for Wirya Dinata Mulia

You are an elite creative developer, senior frontend engineer, digital art director, and UI/UX designer.

Your mission is to design and develop a distinctive, visually sophisticated, and highly interactive personal portfolio website for **Wirya Dinata Mulia**.

This project is not intended to be another conventional developer portfolio.

I do not want a generic portfolio template, a typical SaaS landing page, or a website that looks like it was automatically generated by AI.

I want something that feels like an independent creative project: an experimental digital playground that combines artistic editorial design, unconventional layouts, playful interactions, and warm cinematic aesthetics.

The website should have its own personality, visual identity, and recognizable design language.

The ultimate objective:

**Create a portfolio that people remember, not just a portfolio that people scroll through.**

# 01 — CREATIVE VISION

The main creative direction is inspired by two visual references.

### Reference A: Michael Kolesidis Portfolio

Use the following characteristics as inspiration:

- Playful and unconventional interface.
- Floating windows and overlapping elements.
- Asymmetric composition.
- Large expressive typography.
- Interactive visual objects.
- Personal and experimental design language.
- Unexpected but intentional layouts.
- A sense of exploration and discovery.

### Reference B: Warm Dark Architectural Experience

Use the following characteristics:

- Warm cinematic lighting.
- Dark brown and charcoal environments.
- Muted beige and cream surfaces.
- Atmospheric depth.
- Realistic shadows.
- Minimal but sophisticated visual language.
- Immersive and mysterious environments.

### The Combination

Combine both directions into a cohesive original visual identity.

The final result should feel:

- Experimental but sophisticated.
- Playful but not childish.
- Dark but not depressing.
- Minimal but not empty.
- Artistic but still functional.
- Personal rather than corporate.
- Visually interesting without becoming chaotic.

Do not directly copy the reference websites.

Use them as art direction references, not templates.

# 12 — MANDATORY TECHNICAL STACK

NEXT.JS IS THE REQUIRED FRAMEWORK.

Do not replace it with Vite, plain React, Vue, or another framework.

## Core Technologies

- Next.js — latest stable version compatible with the project.
- React.
- TypeScript.
- Next.js App Router.

## Styling

- Tailwind CSS.
- Custom CSS when necessary.
- CSS variables for design tokens.

## Animation and Interaction

- Framer Motion.
- GSAP only when advanced animation timelines are genuinely necessary.
- React Three Fiber / Three.js only when meaningful 3D experiences are required.

## Icons

- Lucide React.

## Architecture

Use Next.js App Router.

Use Server Components by default.

Use Client Components only when browser-side state, event handling, or interactive functionality is required.

Build reusable and maintainable components.

Keep animations and interaction logic modular.

Use Next.js Image for optimized image handling where appropriate.

Implement:
- SEO metadata.
- Semantic HTML.
- Accessibility.
- Responsive behavior.
- Proper loading and error states.

## Performance

Prioritize:

- Fast initial loading.
- Optimized images and assets.
- Lazy-loaded heavy visual components.
- Dynamically imported Three.js components when needed.
- Minimal unnecessary client-side JavaScript.
- Prevention of layout shifts.
- Smooth mobile performance.

Do not overengineer the application.

Start with Next.js, Tailwind CSS, and Framer Motion.

Do not introduce Three.js unless the visual result genuinely benefits from it.
